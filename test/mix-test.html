MAI SOUND STUDIO

設定

YouTubeのBGMを止めずに効果音を重ねられるかを、iPad実機で確かめます。録音（マイク）は使いません。

ボタンの割り当て

押したあと、編集したいボタンをタップします。ボタンを指でドラッグして別のボタンに重ねると、入れ替わります。終わったら上の「編集中」をもう一度押すと通常モードに戻ります。

このページのボタンの数（列 × 行）

列6
行4

列は2〜8、行は1〜6。減らしても、隠れたボタンの設定は残ります。

音声セッション（他の音との付き合い方）

auto：iPad任せ ／ ambient：YouTubeなど他の音を止めずに重ねる（本命） ／ playback：このページが主役になり他の音を止める（比較用）

再生方式（効果音の鳴らし方）

Web Audio：音を先に読み込んで即座に鳴らす。速く、連打・同時押しに強い（おすすめ） ／ audio要素：ふつうの音声プレーヤー方式（比較用。ボタンごとの音量は効かず、「押している間だけ」は「もう一度押すと止まる」になります）

全体音量（Web Audioのみ）：80%

基本は「auto + Web Audio」→「ambient + Web Audio」の順に試してください。

画面の向き

ホーム画面に追加して開いた場合は、横向き固定の指定が入っています。ただしiPadは、この指定を無視することがあります。その場合はコントロールセンターの「画面の向きのロック」を使ってください。

バックアップ

全ページの設定と、割り当てたMP3を1つのファイル（.json）に保存します。iPadが保存データを消してしまった時や、機種変更の時は、読み込むと元に戻ります。書き出したファイルは「ファイル」アプリに保存されます。読み込むと、今の設定は置き換わります。

判定チェック（YouTubeで音楽を再生しながら）

  1. 効果音を鳴らしても、YouTubeのBGMが止まらない
  2. 効果音の最中、BGMの音量が下がらない
  3. 効果音が遅れず鳴る（連打、同時押しも）
  4. ホーム画面へ戻る・画面をロックした後も、再度鳴る
  5. AG03MK2を接続した状態でも、BGMと効果音の両方が出る
