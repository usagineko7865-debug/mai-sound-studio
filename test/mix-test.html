MAI SOUND STUDIO

設定

YouTubeのBGMを止めずに効果音を重ねられるかを、iPad実機で確かめます。録音（マイク）は使いません。

ボタンの割り当て

押したあと、編集したいボタンをタップしてください。終わったら上の「編集中」をもう一度押すと通常モードに戻ります。

ボタンの数（列 × 行）

列6
行4

列は2〜8、行は1〜6。減らしても、隠れたボタンの設定は残ります。

音声セッション（他の音との付き合い方）

auto：iPad任せ ／ ambient：YouTubeなど他の音を止めずに重ねる（本命） ／ playback：このページが主役になり他の音を止める（比較用）

再生方式（効果音の鳴らし方）

Web Audio：音を先に読み込んで即座に鳴らす。速く、連打・同時押しに強い（おすすめ） ／ audio要素：ふつうの音声プレーヤー方式（比較用。ボタンごとの音量は効きません）

全体音量（Web Audioのみ）：80%

基本は「auto + Web Audio」→「ambient + Web Audio」の順に試してください。

判定チェック（YouTubeで音楽を再生しながら）

  1. 効果音を鳴らしても、YouTubeのBGMが止まらない
  2. 効果音の最中、BGMの音量が下がらない
  3. 効果音が遅れず鳴る（連打、同時押しも）
  4. ホーム画面へ戻る・画面をロックした後も、再度鳴る
  5. AG03MK2を接続した状態でも、BGMと効果音の両方が出る

状態

初期化

割り当てたMP3・名前・音量・ピッチを消して、最初の5音に戻します。

ボタン編集

名前

音

「ファイル」アプリやダウンロードから、MP3・M4A・WAVを選べます。選ぶと名前もファイル名になります（あとで変更できます）。

音量：100%

100%が元の大きさ。150%まで上げられますが、上げすぎると音が割れます。

ピッチ：0 半音

＋で高く、−で低くなります。±12で1オクターブ。音の長さも一緒に変わります（高いと短く、低いと長く）。
